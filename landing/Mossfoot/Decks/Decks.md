This folder is a folder note: it is named after the folder it sits in, so with `folder_notes: true` in `.vaults/settings.yaml` it is served at `/Mossfoot/Decks` instead of getting a generated index. Compare it with `Mossfoot/Lore/index`, which the build wrote.

The Mossfoot Inn keeps one deck behind the bar: the [[Mossfoot Tarot]], six cards the innkeeper's grandmother read futures over. It syncs into Foundry as a Cards document (see [[Foundry integration]]).
